If E_phys(u)=E_scaled(s*u)/s, equal input/output scaling cancels from the physical Lipschitz constant.
If histories including their last sample are multiplied by w, the endpoint contribution is b*w(0)^2. The notebook's printed diagnostic omits this endpoint factor when w is normalized.
The exact finite-delay quadrature certificate uses sum(w^2)*dt, which can exceed the continuous integral for an inclusive rectangular grid.

Conclusion:
For the unnormalized code weight exp(10*tau), the thesis parameter must be lambda=20 under w=exp(lambda*tau/2). The reproduced squared certificate is below 0.998, but 0.998 is a conservative bound rather than an exact equality. The printed lambda=10 convention does not pass this sufficient test at the stated gamma.
